### Fixed

- **The pentest evidence pack's `cosign verify-blob` identity regexp now compiles under Go's RE2 (org migration I4).** The pack's MANIFEST printed `--certificate-identity-regexp '\A…\Z'`. cosign is a Go program and compiles this flag with Go's `regexp` (RE2 syntax), which has no `\Z`. Rendering the MANIFEST heredoc through bash and passing the printed regexp to Go `regexp.Compile` returned `invalid escape sequence: \Z`, so the documented verification could not get past compiling its identity regexp. The anchors are now `^…$`, which mean start and end of text in RE2 without the `m` flag. RE2 and the Python 3.12 test runner both accept them, and `\z` is not an option because Python 3.12 rejects it. The same rendering now compiles and gets an 11-case owner/lookalike matrix right. The identity test matched with `re.fullmatch`, which adds anchors of its own, so it could not have noticed a pattern that lost its anchors. It now uses `re.search`, matching unanchored like Go's `MatchString`. It also rejects SANs embedded after a prefix or before a newline, and fails on `\z`/`\Z`. Four anchor mutations (the old `\A…\Z`, a trailing `\z`, no `^`, no `$`) each turn it red. cosign itself was not run.
