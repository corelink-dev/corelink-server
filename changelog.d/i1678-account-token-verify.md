### Fixed

- **The B-216 DSR receiver readback now verifies account-owned Cloudflare tokens at the account endpoint (#1678).** The token diagnostic only called `/user/tokens/verify`. Cloudflare returns 401 there for an account-owned token, even one that works, so the readback reported `verify_unknown` for a token that had just listed the account's Workers. When the user endpoint returns 401 or 403, the diagnostic now tries `/accounts/<target>/tokens/verify` once, then reads the token's policy from the endpoint that verified it. The account paths are allowed for the fixed target account only. The `verification` summary now records `token_kind` (`user`, `account` or `unknown`), plus the HTTP status and error class of each verify endpoint. It still never records the response body, the token or the token ID.
