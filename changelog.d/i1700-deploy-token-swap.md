### Fixed

- **The #1700 native staging proof ran with a staging Cloudflare token that no longer has the permissions it needs (#1700).** V13 (run 36976287686) failed closed at the bootstrap secret PUT on `corelink-staging`, and the B-216 readback (run 37028034683) showed the same `STAGING_CF_WORKER_API_TOKEN` getting HTTP 403 on Worker version reads. That token is account-owned and active, but it cannot read its own policies, and Wrangler OAuth cannot mint a replacement. The deploy job now uses the repository's existing Cloudflare deploy token, `CF_API_TOKEN`, which the same workflow's `historical_query` job already uses in the `staging` environment. Staging lives on the same account, and every step keeps its exact-name, preimage and rollback guards.
