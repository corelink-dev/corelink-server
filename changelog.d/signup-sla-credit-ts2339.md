### Fixed

- **The signup worker typecheck failed on the B-089 SLA credit test, which turned unrelated PR checks red.** #2774 added a `measurement_tier` field to the in-memory D1 double in `apps/signup-worker/tests/sla_credit_cron.test.ts` by spreading each ledger row (`Record<string, unknown>`) into a new object. Spreading a type that only has an index signature drops the signature, so TypeScript narrowed the mapped row to `{ measurement_tier: unknown }`, and the filter and sort that read `status`, `next_attempt_at_ms` and `lease_until_ms` failed with TS2339. `tsc --noEmit` exited 2, so any lane that typechecks `@corelink/signup-worker` failed there. Runs 37033076235 and 37033076262 show it failing the `contract` job of `issue-2623-ownership-contract.yml` and the `scoped-proof` job of `issue-2580-webhook-ownership.yml`. `issue-2582-signup-ownership.yml` runs the same typecheck, but its observed runs stopped earlier, at its change-scope step. The map callback is now annotated to return `Row`. That is the same `Record<string, unknown>` type that the production `SELECT l.*, m.tier AS measurement_tier` query in `sla_credit_cron.ts` reads through `all<Record<string, unknown>>()`. Production code, assertions and test behaviour are unchanged.
