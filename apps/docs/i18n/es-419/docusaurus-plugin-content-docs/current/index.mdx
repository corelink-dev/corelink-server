# CoreLink documentation

CoreLink is a multi-tenant content-addressable cache for build, package,
and ML workloads, deployed on Cloudflare. These docs follow the
[Diátaxis](https://diataxis.fr/) framework — every page belongs to
exactly one of **Tutorial**, **Cómo hacer**, **Referencia**, or **Explicación**.

## New to CoreLink?

Start with **[Tutorial → Build your first cached project](/tutorial/)**
for a guided walkthrough, then dive into the **[Cómo hacer](/how-to/)**
guides for task-oriented recipes (BYOK setup, Bazel CI integration, DSR
exports, and more).

## Looking for something specific?

- **API and CLI reference**: [`/reference/`](/reference/) — REAPI v2,
  Python/Go/JS SDKs, CLI commands.
- **Architecture and design rationale**:
  [`/explanation/architecture`](/explanation/architecture) — why
  content-addressable, how dedup works, the multi-region model.
- **Confianza and compliance**: [security policy](/security) — SBOM, internal
  adversarial-review posture, SOC 2 timeline, SLA. No external penetration
  test has been commissioned yet.
