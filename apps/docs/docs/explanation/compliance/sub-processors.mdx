# Sub-processors

> **DRAFT — pending Legal + Finance + Security review.** The authoritative
> machine-readable source is `legal/sub-processors.md`. This page mirrors that
> file for procurement teams who cannot pull from the repository.

## Notification policy

CoreLink commits to a **30-day prior notice** before any new sub-processor
begins processing customer personal data. Notices are sent by email to the
account owner contact; there is no automated notice delivery yet.

## How to receive change notices at another address

Email `privacy@humangr.com` with the address that should also receive
sub-processor change notices and your tenant identifier. There is no notice
setting in the product.
