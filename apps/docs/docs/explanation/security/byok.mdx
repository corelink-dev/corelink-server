# BYOK — customer-managed keys

> **PRELAUNCH DRAFT — NOT OFFERED OR AVAILABLE.** CoreLink has not launched and
> has no customers. Legal, Finance, and Security review remains pending. This
> page describes a proposed design, not an active customer feature or SLA.

BYOK is not available or offered in CoreLink's prelaunch service. The repository
contains a real AWS KMS provider implementation and an envelope-encryption
design, but no accepted authenticated customer-controlled KMS lifecycle receipt
from the shipped CoreLink runtime establishes an operable customer feature.
Current service source uses provider-managed R2 encryption; BYOK does not cover
the shared D1 control plane. The current limitation is also recorded in
`docs/customer/byok-kill-switch.md`.

## Provider design status

| Provider | Provider module information | CoreLink BYOK status |
| --- | --- | --- |
| AWS KMS | See `compliance/byok-fips-matrix.md` | Runtime lifecycle unverified; not offered |
| GCP Cloud KMS | See provider module matrix | Design only; not offered |
| Azure Key Vault Premium | See provider module matrix | Design only; not offered |
| HashiCorp Vault Enterprise | See provider module matrix | Design only; not offered |

Provider module certification and source code do not establish CoreLink runtime
availability, customer-controlled key custody, or a security/compliance approval.

## Operational boundary

- Key activation, revocation, rotation, crypto-erase, and break-glass behavior
  remain unverified in an accepted customer-controlled KMS lifecycle.
- No BYOK kill-switch timing SLO or p99 measurement is offered. The former
  five-minute claim is not a verified runtime result or customer commitment.
- The real-KMS lifecycle and production-binary revocation timing are tracked
  by [#1653](https://github.com/HuGR-dev/corelink-server/issues/1653) and
  [#2165](https://github.com/HuGR-dev/corelink-server/issues/2165).

## Limitations

- No tier currently offers BYOK. Future availability requires accepted
  exact-image provider/runtime evidence and owner approval.
- This page is not an executed customer instrument or legal approval.
